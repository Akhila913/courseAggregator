# LearnXcs - Online Learning Resource Aggregator

**LearnXcs** is a full-stack web app that helps users discover the best **courses**, **videos**, **practice problems**, and **open-source projects** on any topic.  
It gathers resources from platforms like:

- Udemy  
- Coursera  
- YouTube  
- GeeksforGeeks  
- LeetCode  
- GitHub  
- Codeforces  
---
## Features
- Search for learning resources on any tech topic  
- YouTube tutorial integration  
- Curated courses from Udemy & Coursera  
- Programming practice problems from GFG, LeetCode, and Codeforces  
- Project suggestions from GitHub  
---
## Tech Stack
### **Frontend**  
- HTML  
- CSS  
- JavaScript  
### **Backend**  
- Node.js  
- Express.js  
### **APIs Used**  
- Google Custom Search API  
- YouTube Data API  
- Coursera API  
- GitHub API  
- LeetCode API (Unofficial)

## Future Enhancements
- Integrate user authentication via Firebase (Google Sign-In)
- Add personalization features: suggest resources based on user interests and activity
- Enable bookmarking and saving favorite resources

- Introduce user profiles and learning history tracking
